# Household Stocking

The catalog of things [Your name] regularly needs, separate from the words they use to ask for them. [Shortcuts](../Personal%20Agent%20Instructions/Shortcuts.md) link here.

Use one row per item in [Inventory.md](Inventory.md): the exact item and variant, retailer, budget, replacement rule and source/date. Quantities on hand stay unknown until checked. A category list is not a shopping list.

This catalog creates no automatic reordering or purchase authority. Check availability, price, shipping address and checkout total before each order.
