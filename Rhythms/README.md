# Rhythms

Habits and activity logs live in a Google Sheet: [link your Rhythms Google Sheet here]. It's the operational log; this folder only describes it. Don't keep a second editable log here.

## Sheet structure

### ActivityLog

- Date
- HabitID
- Activity
- Category
- Amount/duration
- Notes

### HabitDefinitions

- HabitID
- Habit
- Type
- Goal/interval
- Unit
- Status
- Notes

## Context

[Context.md](Context.md) holds weekly anchors and recurring-support requests. It's reference context, not an activity log or proof that reminders are running. Rhythms tied to a person (friend hangs, checkups) live in [People/rhythms.csv](../People/rhythms.csv).
