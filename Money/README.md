# Money

Money admin agents can help with: subscriptions, memberships, renewals and recurring bills. Never put account numbers, card numbers, passwords or ID numbers here (see [Boundaries](../Personal%20Agent%20Instructions/Preferences.md#boundaries)).

| File | What goes there |
| --- | --- |
| [Subscriptions.md](Subscriptions.md) | One row per subscription or membership, with renewal date and cost. |

The default payment card preference lives in [Preferences, Shopping](../Personal%20Agent%20Instructions/Preferences.md#shopping). This folder gives context; it is not permission to pay, cancel or change anything.
