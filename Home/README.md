# Home

Everything about keeping [Your name]'s home running: who to call, what's due each season and what's been fixed. The home address lives once, in the `me` rows of [People details](../People/person_details.csv).

| File | What goes there |
| --- | --- |
| [Maintenance.md](Maintenance.md) | Recurring home upkeep: one row per task, with season or interval and who does it. |
| [Repairs.md](Repairs.md) | A log of repairs and service visits: one row per visit. |
| [People/providers.csv](../People/providers.csv) | Service providers (plumber, electrician, HVAC, gardener, cleaner and so on). They live with the family's other providers so each business is listed once. |

Household products and reorders live in [Household Stocking](../Household%20Stocking/README.md). The car lives in [Vehicles](../Vehicles/Car.md).

Leave unknown cells blank rather than guessing, add the source and date to each row, and link a provider by its provider_id. This folder gives context; it is not permission to book or pay.
