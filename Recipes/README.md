## Format

Use ingredient-to-step charts: ingredient quantities in left-hand rows, with shared or merged action columns for preparation, combining, cooking or baking, and cooling where the source supports them. Use HTML tables when merged cells are needed.

Keep exact source quantities and the source link. Mark missing directions rather than inventing them, and don't silently substitute a different version of the recipe.

The preference is recorded in [Preferences](../Personal%20Agent%20Instructions/Preferences.md#recipe-format).
