# Reactions

Dated feedback on specific agent messages. Agents use these as examples of tone and personality. A reaction applies only to its target; it does not authorize another action or set a broader preference by itself. General reaction meanings are in [Personal Agent Instructions](README.md#reactions).

Add new entries at the top, in this format:

## YYYY-MM-DD: short description

- Agent: [which agent].
- Context: [what was going on].
- Message excerpt: "[the line that got the reaction]".
- Reaction: [e.g. laughed, ❤️, 👎].
- What it means: [e.g. good humor example; do more of this].
